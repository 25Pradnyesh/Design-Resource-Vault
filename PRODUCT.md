# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Product designers, frontend engineers, creative technologists, and design leads discovering benchmarks, UI/UX inspiration, animation and motion references, and design system components.

## Product Purpose
Design Resource Vault is a curated, visual-first archive designed to replace scattered bookmarks and unorganized browser tabs with an editorial, highly structured reference repository. Success means frictionless discovery, instant visual inspection, and deterministic organization of elite web and product design resources.

## Positioning
An editorial visual reference engine combining deterministic previews, rich design-domain taxonomies, instant multi-attribute command search (`⌘K`), and local-first persistence without bookmark bloat, social noise, or generic list views.

## Operating Context
- Web-based design discovery during active UI/UX ideation, benchmarking, moodboarding, and creative frontend development.
- Key workflows: rapid searching via `⌘K`, multi-faceted filtering across categories and tags, visual blueprint previews, detail inspection, URL metadata importing, and local bookmark curation (Favorites and Recently Viewed).

## Capabilities and Constraints
- Curated resource database with deterministic SVG blueprint fallbacks and live screenshot previews.
- Deep multi-category taxonomy spanning Inspiration & Web, Interaction & Motion, Visual Systems & Assets, and Product & Engineering.
- Fast multi-attribute scoring and natural language search intent parsing.
- Keyboard-first command palette (`⌘K` / `Ctrl+K`) and multi-category filtering with OR logic.
- Local-first client persistence via StorageAdapter (Starred favorites, recent history, custom additions).
- Technical constraint: Next.js 15 App Router, React 19, Tailwind CSS v4 tokenized system.
- Strict color restraint: Excludes purple, violet, indigo, lavender, and blue-dominant gradient treatments in favor of clean slate surfaces and warm/electric accents (Aqua, Mint, Orange, Coral, Yellow).

## Brand Commitments
- Name: Design Resource Vault.
- Voice & Tone: Editorial, precise, design-tool aesthetic, structured, and craft-focused.
- Visual Identity: Crisp white/slate canvas surfaces (`#FFFFFF`, `#F8FAFC`), deep navy/slate ink typography (`#0B132B`, `#334155`), multi-color iris emblem, and warm/tactile accents.

## Evidence on Hand
- Seed database in `data/resources.ts` containing 100+ curated design resources across 20+ specialized categories (`data/categories.ts`).
- Production-grade UI components with custom scroll-blending header chrome, drawer taxonomy index, interactive WebGL canvas effects, and responsive grid layouts.

## Product Principles
1. **Visual-First Recognition**: Lead with immediate visual previews and blueprint aesthetics over dense text or generic link lists.
2. **Speed & Keyboard Fluency**: Instant response times via global `⌘K` palette, faceted filtering, and zero layout shift.
3. **Editorial Curation over Clutter**: Maintain high aesthetic standards, rigorous taxonomy categorization, and noise-free presentation.
4. **Local-First Privacy**: Instant bookmarking and personal history preserved seamlessly in client storage.

## Accessibility & Inclusion
- Full keyboard navigability across search, filtering, and modal flows.
- High-contrast text pairings (Deep Navy ink on Slate/White backgrounds).
- Responsive adaptation across mobile viewports (390px+), tablets, and desktop displays.
